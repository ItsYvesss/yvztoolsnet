# 🚀 YVZTOOLS

## DOWNLOAD YVZTOOLS

### ⭐ [DOWNLOAD YVZTOOLS INSTALLER](https://github.com/ItsYvesss/yvztoolsnet/releases/latest/download/YVZTOOLS-INSTALLER.exe)

Download the installer, run **YVZTOOLS-INSTALLER.exe**, choose where you want the folder saved, and the installer will:

- 🪟 Open as a normal Windows app with a title bar and taskbar entry
- 📁 Let you choose the install location
- ⬇️ Download the latest YVZTOOLS files
- 📦 Create the **YVZTOOLS** folder
- ⚡ Install **YVZNETMATH.exe**
- 🔄 Install **YVZUPDATER.exe**
- ▶️ Launch YVZTOOLS when finished

Your folder will look like:

```
YVZTOOLS/
├── YVZNETMATH.exe
├── YVZUPDATER.exe
└── version.txt
```

## Features

- 🌌 YVZTools NetMath Space dashboard (v6.3)
- 🪟 Responsive window resizing with adaptive header spacing to prevent UI overlap
- 🔄 Update status checks GitHub every 10 seconds and shows UP TO DATE or UPDATE AVAILABLE
- 🚀 Cinematic v5.8 startup sequence with layered space glow, orbiting reactor, drifting particles, and eased progress animation
- ✨ Smoother space background, button hover, and AI progress animations
- 🔧 Fixed updater launch path for packaged Windows builds
- 🖱️ SCAN FULL button: one tap scans the current Chrome question and sends it to Gemini (same workflow as shortcut 1), with screenshot support
- 🌐 START CHROME (R) opens a profile chooser for Main Chrome or a separate automation profile, both using the port 9222 connection workflow
- 🧠 Smart question solving
- 🌐 Chrome/DevTools integration
- 🎨 v6.3 theme polish: Oreo uses cocoa-and-cream colors without green accents; YVL adds royal-purple details, King Carson crown branding, supplied artwork, and a larger high-contrast Copy Answer button
- 🌓 Copy Answer uses theme-aware high-contrast colors for readability
- 🎨 Multiple themes and answer-style customization
- ⌨️ Keyboard shortcuts for fast workflows
- 🔄 Built-in updater with automatic version checks

## Build from source

Run `build_windows_exe.bat` for NetMath, `build_updater.bat` for the updater, or `build_installer.bat` for the installer.
