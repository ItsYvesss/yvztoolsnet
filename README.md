# 🚀 YVZTOOLS

## DOWNLOAD YVZTOOLS

### ⭐ [DOWNLOAD YVZTOOLS INSTALLER](https://github.com/ItsYvesss/yvztoolsnet/releases/download/v3.5/YVZTOOLS-INSTALLER.exe)

Download the installer, run **YVZTOOLS-INSTALLER.exe**, choose where you want the folder saved, and the installer will:

- ✦ Show the animated YVZTOOLS installer
- 📁 Let you choose the install location
- ⬇️ Download the latest YVZTOOLS files
- 📦 Create the **YVZTOOLS** folder
- ⚡ Install **YVZNETMATH.exe**
- 🔄 Install **YVZUPDATER.exe**
- ▶️ Launch YVZTOOLS when finished

Your folder will look like:

```
YVZTOOLS/
├── YVZNETMATH.exe
├── YVZUPDATER.exe
└── version.txt
```

## Build from source

Run `build_windows_exe.bat` for NetMath, `build_updater.bat` for the updater, or `build_installer.bat` for the installer.
