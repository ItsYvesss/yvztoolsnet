# YVZTOOLS NetMath Space — v2.8

### UI update
- Removed the updater system. This release is back to the normal project structure.
- Startup now asks which theme you want before opening the main app.
- Four themes:
  - 🌌 Space Blue
  - 🌸 Cotton Candy
  - ☠ Hacker Green
  - 🔥 Crimson Red
- Theme choice is saved for the next launch.
- Animated background adapts to every theme.
- Improved control deck with clearer keyboard controls:
  R = Start Chrome
  Y = Scan
  A = Solve
  1-4 = Quick solve presets
  T = Theme selector
  X = Exit
- Existing Gemini progress/loading UI remains.

Build on Windows with `build_windows_exe.bat`.


### EXE build
Run `build_windows_exe.bat`. The executable is created directly in this folder as `YVZNETMATH.exe` instead of inside `dist`.
